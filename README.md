# Daily Planner

## Description
Daily Planner is a web application that helps users organize their daily activities, manage tasks, and keep track of their schedules.

## Features
- User Registration and Login
- Add, Edit, and Delete Tasks
- Task Categories
- Search and Filter Tasks
- Calendar View
- Notifications and Reminders
- User Profile
- Dark and Light Mode

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase

## How to Install and Run
1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not yet installed.
4. Open `index.html`, right-click, and select **Open with Live Server**.
5. The Daily Planner will automatically open in your default web browser.
